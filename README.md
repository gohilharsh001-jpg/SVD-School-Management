# SVD School Management

Shree S.V. Doshi Highschool Kumbhan — school management website.

- Main web app: `index.html`
- Student portal: `student_portal.html`
- Current audited application version: **v1.7.1**

The standalone app stores its working database in browser local storage. Supabase multi-device sync is an explicit feature that must be configured and tested for the school project. Download and verify a JSON backup before any restore or release. No production database reset or schema migration is included in this release.

See `AUDIT_REPORT_v1.7.1.md` for the changes and validation limits.
